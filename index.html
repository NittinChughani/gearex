THE EXECUTION EXPLORER

Follow what the computer does.

For Python, C, C++, Java and JavaScript, visualize real execution using Python Tutor: executed lines, variable changes, call stacks, heap objects and output. C# and SQL currently offer guided annotations only.

No steps prepared

Real execution tracing for five languages is provided by Python Tutor (created by Philip Guo). Clicking Visualize execution sends your current code to that third-party service. Do not enter passwords or private information. It supports small single-file examples, not every library or asynchronous JavaScript feature. The C# and SQL fallback does not execute code.

LEARN · ASSESS · ACHIEVE

Earn a certificate by demonstrating what you learned.

Each lesson ends with five questions. Pass with 4/5 to complete it. Finish all lessons and pass the final assessment with at least 70%. Your certificate reports lesson-check marks (70%), final assessment marks (30%), and a combined score out of 100.

Certificates are creator-issued records of self-paced completion, not accredited qualifications. A certificate name is confirmed once and then locked in the interface, but browser storage can be modified or cleared; identity and scores are not independently verified.
