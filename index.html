06 / THE VISUAL EXPLAINER

Watch variables move. Understand why.

GearEx builds a local execution timeline for foundational statements, loops, functions, arrays and objects. Follow active code lines and watch the call stack, heap and output update. Headers and namespace directives appear as setup notes; full library behavior belongs in the Compiler. It detects the language, checks common syntax mistakes and shows their source lines before tracing. It can pause for input, and you can choose manual or automatic playback.

The GearEx trace engine is an original, browser-local educational interpreter, not a complete implementation of the seven languages. It accurately models supported fundamental operations, while advanced syntax and libraries may stop with a coverage note. SQL displays a conceptual query plan, not database execution. For actual compilation or complete program results, use the compiler.

LEARN · ASSESS · ACHIEVE

Earn a certificate by demonstrating what you learned.

Each lesson ends with five questions. Pass with 4/5 to complete it. Finish all lessons and pass the final assessment with at least 70%. Your certificate reports lesson-check marks (70%), final assessment marks (30%), and a combined score out of 100.

Certificates are creator-issued records of self-paced completion, not accredited qualifications. A certificate name is confirmed once and then locked in the interface, but browser storage can be modified or cleared; identity and scores are not independently verified.

PRIVACY & TRUST

Your learning belongs to you.

GearEx is free and works without an account. We keep the information we collect limited to what is needed to save your progress.

Guest learning

Lessons, scores, code drafts, preferences and optional profile photos are stored in your browser on this device. They are not automatically uploaded while you are a guest. Removing browser data can erase them, so you can export a backup from the Dashboard.

Optional cloud accounts

If you choose to sign in, Supabase handles authentication and stores your account email, your display name and photo, completed work, quiz scores and drafts. Only you should be able to access your own cloud records through database access policies. You can choose whether to import existing guest progress.

Running code

When you press Run in the compiler, source code and any supplied program input are sent to OnlineCompiler.io for execution. Do not enter passwords, financial details, or other sensitive information into programs. The browser-based Code Visualizer runs locally for its supported teaching subset.

Control your data

Export your progress, remove your profile photo, clear learning progress or delete your account from Dashboard settings. Account deletion requires the secure deletion function to be configured in your Supabase project. A profile photo is stored privately, not published to a public gallery. GearEx does not sell learning profiles.
